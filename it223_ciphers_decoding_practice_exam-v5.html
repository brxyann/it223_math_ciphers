⚡ IT 223 Ciphers & Decoding Quick Reference Cheat Sheet

1. Substitution Operations

• Fixed Replacement (+1): Replace each letter with the next (Z → A). Inverse: previous letter (A → Z).
Slide Ex: HELLO → IFMMP

• Caesar Cipher (Variable, k = 3): Shift forward 3 letters. Inverse: shift back 3 letters.
Slide Ex: HELLO → KHOOR

• 4-Bit Table Lookup: Outer 2 bits = Column; Inner 2 bits = Row.

2. XOR & Vernam Cipher (One-Time Pad)

• XOR Rule: Same bits = 0 (0⊕0=0, 1⊕1=0); Different bits = 1 (0⊕1=1, 1⊕0=1).

• Self-Inverse: Plaintext ⊕ Key = Ciphertext and Ciphertext ⊕ Key = Plaintext.

• One-Time Pad Rules: Truly random values, used ONLY ONCE, pad as long as message, securely distributed & guarded.

3. Transposition Operations

• Spartan Scytale: Ancient physical transposition cylinder.

• Swap: Split even block into 2 equal halves & swap (ABCD → CDAB, 01010011 → 00110101). Inverse = Swap again.

• Rotation (Circular Shift): Shift right/left wrapping around (ABCD → DABC right 1; 01010011 → 10011010 left 3). Inverse = Rotate opposite way.

• Arbitrary Transposition: Permute by index rule (e.g., 4132 turns ABCD → DACB).
